    Offline setup & evidence notes

    1. Supply the actual clips

    The selected upload option is “Upload clips now,” but no user clips are present yet. Supply closeup.mp4 and traffic.mp4 yourself. No replacement footage is generated. This template remains usable for manual checks without media.

    Run the following in Windows PowerShell from the project folder once the companion prepare_videos.py tool and clips are available. The browser does not upload or analyze video; extraction and embedding happen locally in the tool.

    2. Isolate Python 3.12 and inspect the tool

    py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install "fast-alpr[onnx]==0.4.0"
.\.venv\Scripts\python.exe prepare_videos.py --help
.\.venv\Scripts\python.exe prepare_videos.py extract --help
.\.venv\Scripts\python.exe prepare_videos.py embed --help

    Do not change the host OpenCV installation. Initial package installation and the first model load require downloads. After preparation, the generated HTML plays locally with zero browser network requests; there is no CDN or browser inference.

    3. Extract actual plate tracks

    .\.venv\Scripts\python.exe prepare_videos.py extract --video closeup.mp4 --source-id closeup --output closeup.json
.\.venv\Scripts\python.exe prepare_videos.py extract --video traffic.mp4 --source-id traffic --output traffic.json

    Use upright constant-frame-rate clips, preferably browser-compatible H.264 MP4. Variable-frame-rate input must be normalized to a new file first; then extract and embed that same file. If timestamps cannot be verified, --assume-cfr explicitly accepts the assumption and records it. Do not use it to disguise known variable timing.

    4. Optional, explicitly assigned demonstration plates

    Review actual track IDs and raw OCR in the extracted JSON. To assign fictional sample records to unreadable tracks, create a separate assignments.json mapping IDs to strings, for example:

    {"3": "LEA-19-4521", "8": "LEE-17-6240"}

    These strings are assigned demo plates — not OCR. Use a separate mapping for each source if needed. Rerun extraction with the mapping and either a new output path or explicit --force to replace the previous extraction:

    .\.venv\Scripts\python.exe prepare_videos.py extract --video closeup.mp4 --source-id closeup --output closeup.json --demo-assignments assignments.json --force

    Raw OCR and its confidence are retained separately. Centroid tracking can split or merge identities at crossings or occlusions; reviewed canonical vehicleId values in track metadata can correct identity grouping. The interface never infers identity from a plate string.

    5. Embed both videos, then open the output

    Call --help before embedding. Both real clips and their matching extraction outputs are required. The tool validates SHA-256 hashes and the shared schema. Never modify or re-encode a clip between extraction and embedding.

    .\.venv\Scripts\python.exe prepare_videos.py embed --help
.\.venv\Scripts\python.exe prepare_videos.py embed --template index.html --closeup-video closeup.mp4 --closeup-data closeup.json --traffic-video traffic.mp4 --traffic-data traffic.json --output TaxTrackAI.html
Start-Process .\TaxTrackAI.html

    Existing output files require explicit --force; input media must never be overwritten. In PowerShell, use semicolons to separate commands if putting them on one line. Base64 increases media size by roughly one third; favor short clips without sacrificing plate detail.

    How this demonstration works

    • One muted, looping decoder supplies actual pixels to the camera canvas. REC is a replay overlay, not a live recording or transmission. The clock is elapsed clip time.
    • The six stages present precomputed metadata over approximately 1.5 seconds of media time, shortened near the clip end. Vehicle detect is an illustrative plate-track proxy, not a fabricated whole-vehicle detector.
    • Typing presents precomputed OCR text or explicitly assigned demo text; it is not live browser OCR. Reduced-motion mode shows the available text without character animation.
    • A crop is captured only from matching decoded plate coordinates. If the exact evidence frame is skipped, the crop is labeled as a sampled frame, or shown as unavailable; no text or image is manufactured.
    • Paid token tax plus valid registration is compliant. Unpaid, expired, unknown, or unreadable evidence is flagged with every reason. Unknown dues are excluded from totals.
    • One verdict is counted per source plus canonical vehicle identity. Replays and source switches preserve this session-wide set even after older log rows disappear. Manual input is separate. Reset clears the session and restarts the selected source.
    • Pause freezes video and stage progress. If the browser blocks autoplay or cannot decode a clip, use Resume or the recovery action. Switching sources cancels pending work without clearing camera totals.
    • Session results are held only in memory. Only the theme preference is stored when local storage is available; direct-file restrictions are safely ignored.
